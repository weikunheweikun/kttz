# 快艇骰子 · 留骰对决 V7

一个无需框架、无需自建后端的静态浏览器游戏。**仅有两个玩法：挑战 AI、P2P 联机。** 支持手机与桌面。

**没有本地存档。** 刷新、关闭页面或离开会丢失该设备当前局面；P2P 断开后没有持久化恢复。

## 计分规则

- 标准 13 格：1–6 点、三条、四条、葫芦、小顺、大顺、快艇、机会。
- 每人最多 3 次掷骰，每轮第一掷必须手动点击；5 颗骰子的点数 1–6 **由浏览器 `crypto.getRandomValues` 独立等概率生成**，使用拒绝采样避免取模偏差。
- 原上栏 63 分奖励 +35 分。快艇由标准 50 改为 **60 分**，无额外快艇奖励及 Joker 规则；五条也可以计葫芦 25 分。
- **关键！！！本轮选定一个计分格后，若还有下一轮，可花费 3 分 / 颗保留 0–5 颗骰子到自己下一轮。它们默认锁定但可以解除并重掷。最后一轮结束后不能再付费留骰。**
- 可以在尚未填写的类别主动计入 0 分。
- 最终总分 = 上栏 + 额外奖励 + 下栏 − 留骰费用。游戏结束会自动出现**双方统计总结弹窗**，也可以关掉查看完整计分卡。

## 关于 P2P 直连

- WebRTC DataChannel；无需自建信令服务器，通过聊天软件人工交换 offer / answer 码。
- 通过公共 Google STUN 服务发现可用连接路径。游戏数据经 WebRTC 加密数据通道直接传输，**未配置 TURN 中继**。
- 运营商 NAT、公司防火墙及严格网络可能导致直连失败；移动端切出页面也可能导致连接中断。跨实际运营商与设备的连接可靠性尚未获得完整端到端验证。
- 创建方是对局状态权威，使用本地 `core.js` 的随机数产生结果并同步给对方。它是好友之间的休闲对战，**不提供防作弊、联机断线持久化恢复或自动匹配**。
